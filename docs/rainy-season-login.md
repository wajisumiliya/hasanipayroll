# Rainy-season desktop login

The approved rainy-season backgrounds rotate using the device's local weekday.
The existing `assets/login_days/<weekday>.png` mapping supplies the desktop login
(width 880 pixels and above). The compact mobile login keeps its arctic scenes.

| Day | Scene |
| --- | --- |
| Monday | Rainforest Dawn |
| Tuesday | Rain on the Lake |
| Wednesday | Monsoon Waterfall |
| Thursday | Mountain Rain |
| Friday | After the Rain |
| Saturday | Night Rain |
| Sunday | Quiet Rain Garden |

The backgrounds contain scenery only. The Hasani Books logo, sign-in form,
golden mystery egg, hatch countdown, and penguin growth remain rendered by the
app in their existing positions. Images are bundled locally and need no image
hosting service.
